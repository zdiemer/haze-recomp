Haze Recomp 0.1.8 for Windows x64

Reduces recurring gameplay work with asynchronous input-prompt atlas loading,
validated fragment-shader metadata reuse, and reuse of four additional verified
physics workers. Retains sampler descriptors across bounded heap pages to avoid
repeated mid-frame GPU completion waits. Doubles the bounded texture-content
cache limits from 64 to 128 MiB each for CPU and GPU content, reducing repeated
texture allocations in the tested opening scene.

Remembers exact graphics-pipeline recipes and prepares known pipelines before
gameplay on later launches. New or unsupported pipelines still use the normal
creation path. Recipe and shader-bundle persistence share the existing bounded
native-quit timeout and preserve prior archives when replacement cannot finish.

The final 60-second later-combat development-build capture averaged 38.34 FPS
at 2560x1440, uncapped with VSync off: median 24.11 ms, p95 34.74 ms, p99 37.32 ms,
and maximum 89.69 ms. One interval exceeded 50 ms; none exceeded 100 ms.
These are checkpoint-specific observations, not an isolated before/after gain
or a guarantee for other scenes and hardware. GPU completion stalls remain.
Focused sampler, pipeline-persistence, metadata and worker regressions passed.
The broader texture WARP fixture also passes after correcting its manual device
setup and sampler-page initialization. The packaged Release build has not had
a fresh gameplay or clean Windows installation acceptance run.

Existing controls, graphics settings, campaign co-op and save support are retained.

Run HazeRecomp-<version>-Setup.exe and select your disc-decrypted Haze USA ISO
(BLUS30094, 01.02 / 01.00). The installer downloads the pinned official RPCS3
helper and verified Sony firmware, prepares the game, and installs the launcher.
Click Play Haze when installation finishes; later use Haze Recomp in Start.
No separately installed RPCS3 or development tools are needed. Internet is
required for first installation. The portable ZIP requires already prepared data.

The installer is unsigned. Windows may display a publisher/SmartScreen warning.
This is experimental software: full campaign completion, online co-op, every GPU
and consistent performance are not validated. Keep backups of your saves.
Setup validates the supported executable and firmware decoder hashes.

SHA256SUMS.txt covers Setup.exe, ZIP, dependency sources and release.json.
release.json records the code and private generated-input commit used by the build.
HazeRecomp-dependency-sources.zip contains matching source and build information
for redistributed open-source dependencies. License texts are inside both packages.
Game assets, firmware files and private generated source files are not included.
