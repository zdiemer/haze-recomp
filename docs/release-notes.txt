Haze Recomp 0.1.14 for Windows x64

Performance update. The game's main thread spends less time in the runtime
around recompiled code, so busy combat runs at a higher frame rate:

- Ordinary guest memory reads and writes take a short fast path. These
  accesses were about 40% of the main thread's work in combat; every special
  case (device windows, SPU reservations, diagnostics) keeps its previous
  handling.
- SPU floating-point arithmetic runs in native registers, which shortens the
  effects jobs the main thread waits for each frame.
- The SPU job loop's per-step checks are cheaper.

In the developer's later-combat benchmark (a fixed checkpoint, frame-locked
camera sweep, RTX 5080 / Ryzen 7 9800X3D), mean frame time fell from about
15.3 ms to about 13.0 ms, roughly 65 to 77 FPS. Each change was measured
separately in alternating A/B runs; the total is the sum of those results,
not a separate 0.1.13-to-0.1.14 comparison. Other scenes and hardware will
differ, and heavy scenes can still drop below 60 FPS.

Also includes selected upstream runtime fixes: an event-queue initialization
race, store-conditional reservation checks, per-thread callback stacks and
re-polling of empty XInput slots. Developers get a frame-locked benchmark
clock for repeatable measurements; it is off unless explicitly enabled.

The A/B gameplay runs used local builds of the same code and private inputs.
The hosted release build has not received an interactive gameplay run or a
fresh Windows installation acceptance test.

Run HazeRecomp-<version>-Setup.exe and select your disc-decrypted Haze USA ISO
(BLUS30094, 01.02 / 01.00). The installer downloads the pinned official RPCS3
helper and verified Sony firmware, prepares the game, and installs the launcher.
Click Play Haze when installation finishes; later use Haze Recomp in Start.
No separately installed RPCS3 or development tools are needed. Internet is
required for first installation. The portable ZIP requires already prepared data.

The installer is unsigned. Windows may display a publisher/SmartScreen warning.
This is experimental software: full campaign completion, online co-op, every GPU
and consistent performance are not validated. Keep backups of your saves.
Setup validates the supported executable and firmware decoder hashes.

SHA256SUMS.txt covers Setup.exe, ZIP, dependency sources and release.json.
release.json records the code and private generated-input commit used by the build.
HazeRecomp-dependency-sources.zip contains matching source and build information
for redistributed open-source dependencies. License texts are inside both packages.
Game assets, firmware files and private generated source files are not included.
