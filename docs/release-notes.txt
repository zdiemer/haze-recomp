Haze Recomp 0.1.12 for Windows x64

Raises gameplay frame rate substantially. The effects batch's square root
and division now run natively; ordinary frames are submitted into two
fence-owned storage slots so the game and renderer overlap; the guest command
ring is handed out in 64 KB segments instead of draining completely at each
wrap; and lifted game code is compiled with a committed gameplay profile
(profile-guided optimization). The frame limiter now paces on a fixed deadline
grid for steadier capped frames, and the launcher can export a diagnostics
report for bug reports.

Gameplay was measured on one PC (RTX 5080, Ryzen 7 9800X3D, 1440p) with an
uncapped later-combat camera sweep, comparing builds in alternating runs.
Average frame time fell from about 21 ms (~47 FPS) before these changes to
about 13.6 ms (~73 FPS). Results on other hardware and in other levels will
differ, and heavy moments can still drop below 60 FPS. The default frame limit
stays at 30 FPS because game timing above 30 FPS has not been verified across
the campaign. This build has not received a full campaign run or a fresh
Windows installation test; asset-free checks and targeted gameplay sessions
were completed.

Preserves the 0.1.11 fixes, the 0.1.9 title-screen Enter fix, and earlier
controls, graphics, campaign co-op and save support.

Run HazeRecomp-<version>-Setup.exe and select your disc-decrypted Haze USA ISO
(BLUS30094, 01.02 / 01.00). The installer downloads the pinned official RPCS3
helper and verified Sony firmware, prepares the game, and installs the launcher.
Click Play Haze when installation finishes; later use Haze Recomp in Start.
No separately installed RPCS3 or development tools are needed. Internet is
required for first installation. The portable ZIP requires already prepared data.

The installer is unsigned. Windows may display a publisher/SmartScreen warning.
This is experimental software: full campaign completion, online co-op, every GPU
and consistent performance are not validated. Keep backups of your saves.
Setup validates the supported executable and firmware decoder hashes.

SHA256SUMS.txt covers Setup.exe, ZIP, dependency sources and release.json.
release.json records the code and private generated-input commit used by the build.
HazeRecomp-dependency-sources.zip contains matching source and build information
for redistributed open-source dependencies. License texts are inside both packages.
Game assets, firmware files and private generated source files are not included.
