Haze Recomp 0.1.11 for Windows x64

Reduces repeated CPU work with vertex-program metadata reuse, ready-aware job
completion waits, guarded native fill/copy helpers, selective PPU memory-read
inlining, and streamlined SPU quadword shifts and rotates. Existing fallback
paths and diagnostic opt-outs remain available.

Targeted correctness regressions and a later-combat gameplay run were completed
for the optimization stack. Other workloads contended for CPU during the final
run, so a gameplay FPS improvement has not been established. This release does
not promise 60 FPS. The final integration with the latest SDK has not received
a new interactive acceptance run or a fresh Windows installation test.

Supersedes 0.1.10, whose release build stopped before packaging: two build-time
guards had not been updated for the integrated SDK revision and the new default
hot-module read inlining. No 0.1.10 binaries were published; game code is
otherwise unchanged from 0.1.10.

Preserves the 0.1.9 title-screen Enter fix and earlier controls, graphics,
campaign co-op and save support. Also includes the integrated SDK fixes for
SPU decrementer overflow and PPU system-call fallthrough.

Run HazeRecomp-<version>-Setup.exe and select your disc-decrypted Haze USA ISO
(BLUS30094, 01.02 / 01.00). The installer downloads the pinned official RPCS3
helper and verified Sony firmware, prepares the game, and installs the launcher.
Click Play Haze when installation finishes; later use Haze Recomp in Start.
No separately installed RPCS3 or development tools are needed. Internet is
required for first installation. The portable ZIP requires already prepared data.

The installer is unsigned. Windows may display a publisher/SmartScreen warning.
This is experimental software: full campaign completion, online co-op, every GPU
and consistent performance are not validated. Keep backups of your saves.
Setup validates the supported executable and firmware decoder hashes.

SHA256SUMS.txt covers Setup.exe, ZIP, dependency sources and release.json.
release.json records the code and private generated-input commit used by the build.
HazeRecomp-dependency-sources.zip contains matching source and build information
for redistributed open-source dependencies. License texts are inside both packages.
Game assets, firmware files and private generated source files are not included.
