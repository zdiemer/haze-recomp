Haze Recomp 0.1.13 for Windows x64

Fixes Enter failing to advance from the "Press Enter to begin" screen. The
previous fix read optional menu history, which is empty on the live title
screen, and mistakenly sent Confirm instead of Start. The port now resolves
the top active page through its validated widget handle. Enter sends Start
at the title and Confirm in ordinary menus; holding it across that transition
cannot also select the next item. Rebound Start keys and controller Start
remain supported, and a dialog above the title still receives Confirm.

The failure was reproduced in the published 0.1.12 game with Windows keyboard
input, and its live page layout was inspected. New regressions exercise that
layout through both the production menu detector and keyboard mapper; they
fail before the fix and pass afterward. Automated input and menu tests cover
short taps, held-key transitions, dialogs and stale widget handles. The fixed
build has not received an
interactive gameplay run or a fresh Windows installation acceptance test.

Includes the performance, controls, graphics, campaign co-op, diagnostics and
save support from 0.1.12. This patch makes no new performance claims.

Run HazeRecomp-<version>-Setup.exe and select your disc-decrypted Haze USA ISO
(BLUS30094, 01.02 / 01.00). The installer downloads the pinned official RPCS3
helper and verified Sony firmware, prepares the game, and installs the launcher.
Click Play Haze when installation finishes; later use Haze Recomp in Start.
No separately installed RPCS3 or development tools are needed. Internet is
required for first installation. The portable ZIP requires already prepared data.

The installer is unsigned. Windows may display a publisher/SmartScreen warning.
This is experimental software: full campaign completion, online co-op, every GPU
and consistent performance are not validated. Keep backups of your saves.
Setup validates the supported executable and firmware decoder hashes.

SHA256SUMS.txt covers Setup.exe, ZIP, dependency sources and release.json.
release.json records the code and private generated-input commit used by the build.
HazeRecomp-dependency-sources.zip contains matching source and build information
for redistributed open-source dependencies. License texts are inside both packages.
Game assets, firmware files and private generated source files are not included.
